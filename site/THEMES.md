# RBXBanland website eras

`rb.siteTheme` controls page styling. It is separate from `rbx.theme`, which controls the desktop shell and is never overwritten by the website-era selector.

- `classic2008`: light-blue page, compact Verdana panels, blue navigation, and banner treatment inspired by late-2000s Roblox pages.
- `blue2010`: cleaner blue/white chrome and wider content frame, inspired by 2010-era homepage and forum layouts.
- `transition2012`: white canvas, dark-blue header, pale navigation strip, and flatter panels inspired by the 2011/2012 transition.

References used for era cues, not shipped assets:

- Web Design Museum, [Roblox in 2012](https://www.webdesignmuseum.org/gallery/roblox-2012)
- Roblox Wiki, [Site Banner history](https://roblox.fandom.com/wiki/Site_Banner)
- Roblox Wiki, [Images of the Roblox website](https://roblox.fandom.com/wiki/Category:Images_of_the_Roblox_website)

All RBXBanland logos, icons, layout CSS, and theme previews remain original. No Roblox logos or remote runtime assets are loaded.
